# 星灯岛 v1.2 · 实战闯关与保真头像

本版继续使用七个固定大小的开放区域、自然卡通渲染和原有故事。主要更新受击规则、三位伙伴的步态、地图挑战，以及根据用户提供照片重新绘制的左上角头像。

## 头像与画面

- 图一对应小馒头，图二对应旺仔。最终头像以照片身份和五官比例为优先，保留脸型、发际线、眉眼、鼻唇、耳朵和原本表情，采用克制的二维插画处理；背景改为低对比森林暖光。
- 旺仔仍在左，小馒头在右；点击头像切换人物。头像使用完整方图、独立名字行和 mipmap 平滑缩放。旧版裁取上半身的逻辑已移除。
- 最终图片在 `assets/portraits_v12/wangzai.png` 和 `assets/portraits_v12/xiaomantou.png`。使用内置 image_gen 生成，最终提示词与人物映射记录在 `docs/PORTRAIT-PROMPTS-v1.2.json`。

## 每次有效妖怪命中至少损失四分之一最大生命

妖怪伤害最后结算为：`max(ceil(最大生命 × 0.25), 难度与护甲、正面被动格挡结算后的普通伤害)`。因此小怪、精英、首领以及远程弹体都不能被高防御装备削弱成小额伤害。重型招式仍可能造成超过四分之一的伤害。

110 点最大生命时，最低每击 28 点。主动走出攻击预警、避开弹道可以躲过；水盾、切换保护和受击后的 1 秒保护仍生效，持续攻击不会在同一瞬间重复扣血。地形、跌落、陷阱继续使用独立伤害规则。血条增加四等分刻度。

## 走路动作

旺仔、小馒头和小龙各有八方向、每方向八帧行走，加各方向静止帧，共 216 张。两位孩子增加腿部 IK、膝弯、脚跟落地到前掌离地的过程、摆臂与身体重心；小龙使用四肢交替步态、折翼、稳定头部和尾部配平。

动画按碰撞后实际移动距离推进；碰墙、停止、暂停不会继续迈步。运行时是二维投影帧，步幅兼顾自然节奏，未声称实现完整三维世界空间锁脚。原始 Blender 角色文件未修改，重渲染工具在 `tools/render_locomotion_v12.py`。

## 每个区域新增三个独立关卡

七区共 21 个可重玩的挑战，蓝色旗标显示入口；完成后记录金、银、铜勋章和最佳时间。首次奖励经验 24、星晶 10，反复游玩不重复领取。挑战可以失败重试，倒下或营地休息会取消当前挑战；已获勋章保留。

| 类型 | 实际操作 |
| --- | --- |
| 限时穿门 | 按顺序穿过标记门，避开沿途危险，在倒计时内完成 |
| 三波战斗 | 清除三轮真实妖怪；走位避招并利用收招窗口反击 |
| 踏板光栅 | 按数字顺序踏入压板，离开后再进入才算新一次触发，并避开脉冲光栅 |
| 移动靶场 | 切换小馒头，用有飞行时间的星矢按顺序击中移动靶；墙体会挡住射线 |
| 护送粮车 | 跟随沿可行路径移动的实体粮车，打败三轮伏击，再到车旁松开制动 |

主线 21 组、63 个目标也已重做：限时障碍、攻击移动封印、短途护送、两波战斗、推箱、转镜、水闸和首领战组合推进。移除原先站位等待摇铃、举盾或使用指定能力即可自动解锁的目标。旺仔盾击与小馒头星矢保留为主动战斗方式。

## 存档与运行

世界存档升级到 v3。等级、装备、已解锁章节保留；v2 世界存档的宝箱、迷雾、营地和已关闭陷阱保留。旧版当前关卡的局部主线目标与机关解法因玩法已更换而重置。新增挑战按区域保存，换同一区域内的主线组不会重复奖励。

双击 `builds/试玩星灯岛.cmd` 启动 Windows 便携版。此启动器将存档放在同目录 `userdata`。可编辑工程为 `project.godot`；Android arm64 预设同步更新为 1.2.0。本次交付包括完整触控源码与 Windows 运行版；尚未生成 APK 或 IPA，尚未进行手机真机验证。

验证结果与构建哈希见 `docs/validation.json`。截图为原生 Godot OpenGL 渲染，位于 `docs/v12-*.png`。
