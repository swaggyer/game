# 星灯岛 v1.1 · 渲染与挑战更新

这次更新针对场景渲染、实体机关质感和妖怪攻击强度。七区开放地图、21组主线及既有存档继续使用。

## 场景与区域地图

场景采用柔和日照、自然植被、草地和泥土材质、动态水面与岸边泡沫，并使用重新建模渲染的高分辨率环境素材。整体为自然卡通渲染；实际地图仍沿用原来的可通行区域和水墙碰撞。

小地图与区域大地图改为矢量地形轮廓、平滑道路和柔化探索云层，移除低分辨率栅格底图及可见的方格迷雾。

## 六类机关

机关保持原来的危险范围、启动节奏、关闭拉杆和存档规则，更新石材底座、铁制尖刺、铜制喷火器、带链条的金属摆锤、木铁弩机、泡沫水涡和坍塌石板的渲染。火焰、水流与机械动作随游戏时钟推进，暂停时保持当前状态。

## 技术与验证

环境库提供12张700×800透明渲染图及可编辑Blender源文件；Godot中使用线性过滤与mipmap缩小采样。地面、道路、水面、岸边泡沫、植被摆动和柔影由CanvasItem材质绘制，保留七区导航与原始碰撞。

成长105项、导航2190项、妖怪85项、陷阱27项、完整流程444项及新版平衡60项，合计2911项检查；另通过角色动作和机关材质绘制专项。实际GPU画面与日志保存在 `docs/v11-*`。

便携包验证已确认96张战斗帧、12张高分辨率环境图及运行时脚点清单完整；Windows程序退出码为0，另已完成实际OpenGL运行截图检查。
