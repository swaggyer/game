# 星灯岛 v1.5.0 · 游戏内检查更新

开始界面新增小型“检查更新”按钮，显示当前版本。启动游戏时后台检查一次GitHub最新正式Release；发现更高版本，显示版本号、更新说明及“前往下载”“稍后”。断网或GitHub暂时无法访问时，自动检查保持安静，不影响开始游戏；手动检查会显示结果，可稍后重试。

进入关卡后才返回的检查结果不会打断战斗，返回开始界面再显示。网络请求异步执行，标题暂停时仍可完成，8秒超时；只访问公开仓库，不需要登录GitHub或提供账号。

点击“前往下载”会打开本仓库官方Release安装包；玩家自行确认下载并在安卓系统中安装。游戏不自动下载、安装，也不会删除旧游戏或存档。新包沿用原签名与包名，可以覆盖升级。

**已有旧版玩家需先手动安装一次v1.5.0，之后才有此按钮和通知功能。**旧安装包未包含联网权限和检查逻辑，不能通过仓库更新自行增加按钮。

今后发布更新时，需要创建更高版本的正式GitHub Release并上传对应APK，例如tag `v1.5.1`、文件 `StarLanternIsland-v1.5.1-arm64.apk`。只提交源码不会触发游戏更新通知；游戏比较的是正式发布版本。草稿和预发布不通知。版本按数字比较，`1.10.0`高于`1.9.0`。

检查入口为 `https://api.github.com/repos/swaggyer/game/releases/latest`。安装包链接仅接受 `https://github.com/swaggyer/game/releases/download/{tag}/{对应文件名}`，不打开Release描述中的任意链接。当前平台没有匹配安装包时使用本仓库该版本发布页；苹果设备仍需个人签名或正式发布签名。

本版继续包含v1.4全部地图渲染、触控、动作预载、音乐缓存及存档性能修复。安卓只新增普通INTERNET权限，游戏内容仍可离线游玩。
