# 星灯岛 v1.0 · 区域、战斗与机关说明

本版将七个故事区域做成固定布局的可探索地图，并补齐双角色动作、妖怪攻击几何和六类陷阱。每个区域对应三组主线，共二十一组；关卡切换沿用同一区域地形，改变当前任务与遭遇。

## 开放区域和任务

每个区域边界为 `Rect2(100,100,3400,2400)`。角色能在草地、广场、庭院等可行走地面自由活动，石路用于指路。水面和墙体参与碰撞；正常探索路线通过桥梁连接，不要求提前获得后续源晶能力。

| 区域 | 实际地形和路线 |
| --- | --- |
| 星溪村 | 中央广场、果园、溪畔花园、住宅与多条辐射连接路；东南池塘不可直接步行穿越 |
| 萤火森林 | 中央湖泊、南北环湖路线、东西岸清地、北侧溪流木桥与支路 |
| 风车原野 | 中央实体断崖迫使绕行，西东麦田有多条连接；南侧河流有两座桥 |
| 月光水乡 | 五座岛屿、横向与纵向桥廊、多条闭环；桥外水域是真正的移动障碍 |
| 旧王遗迹 | 多庭院、实体墙、可通行门洞、中庭水池；不同庭院可以从多个方向进入 |
| 人间裂隙 | 斜向裂隙贯穿区域，北、中、南三座桥形成交替救援路线 |
| 星灯岛 | 外庭与内庭同心环路、中心星池、十字星桥；尾声没有敌人与陷阱 |

每组主线有三处目标、四处宝箱和两处营地。主线点通常可独立访问；首领在前两个目标完成后出现，水闸按顺序调节。地图中的金点表示主线，方块表示已发现宝箱，圆环表示营地；未探索处被迷雾覆盖。大地图显示区域名称与目标编号。

木箱是阻挡人物的独立物体。从不同侧面互动，会沿人物朝向木箱的方向推动 55 像素；压到金色踏板附近才完成。推错方向可以绕到另一侧调整，也可在营地休息，将未完成的木箱恢复到原位。镜台每次互动转动 90°，当前光线与金色目标方向一致才接通；水闸按荷叶、月牙、星星顺序开启。

## 两位主角怎样配合

旺仔适合贴近敌人的收招空隙，小馒头适合保持距离观察弹道。两人共享生命、等级、补给和装备；切换不会清除受击保护或凭空恢复生命。未操控的孩子及小龙沿区域导航跟随。

| 主角 | 普攻行为 | 第三段的作用 | 出手限制 |
| --- | --- | --- | --- |
| 旺仔 | 三段近战，攻击距离依次为 160、185、210 像素；伤害倍率为攻击力的 1.00、1.15、1.70 倍 | 盾击使普通妖怪中断动作并后退；对首领提供核心显露窗口 | 必须在实际距离、朝向和视线内；接触阶段结算一次，不隔墙命中 |
| 小馒头 | 三段铃音弹；自动选择前方可见目标，弹体以 440 像素/秒飞行，最多飞行 500 像素 | 出手时附近 185 像素内的敌人受到回声干扰，普通怪可打断，首领可显露核心 | 弹体需要实际飞到目标，遇阻挡消失；第三段的近身干扰与远处弹体分别判定 |

每段都有起手、接触、跟随和收招四阶段。旺仔三段总时长分别为 0.45、0.52、0.75 秒；小馒头分别为 0.62、0.70、0.82 秒。连续轻点攻击可在动作末段接续下一段；停顿超过 0.85 秒会从第一段重新开始。攻击中保留有限移动，接触时移动最慢，不能用高频点按跳过起手和收招。

两位主角的四方向、三连段、四阶段共 **96 张战斗帧**来自原角色 `.blend` 中的真实骨骼摆姿。脚底基线在渲染后统一，动作直接替换对应帧；敌人也有起跳、缩身、转帆、收甲、抬高和收招等程序表现。

盾纹和铃纹仍以站位配合为主。探索时站稳约 0.65 秒触发对应伙伴动作；首领附近的协作标记能打开核心窗口或反射附近指定弹体。首领不会被普通攻击无限硬直锁住，抓住收招和显露窗口更有效。

龙术在暂停菜单中选择，战斗中情境键保持该技能。微光/星火攻击正面扇区，御风可干扰周围妖怪并短时加速，水罩持续 4 秒免伤且允许短暂踏水，星门向面向方向寻找安全落点。龙术共用 6 秒冷却，释放前有动作时间；水罩结束时仍在水中会返回最近安全地面。

## 妖怪攻击和反击机会

下表起手时间为星灯探险家/勇敢冒险家的基础值；小小守护者额外增加 0.3 秒。预警图形来自攻击使用的方向、落点、距离和范围数据。弹体会实际飞行，冲刺和跃击会实际移动；一个攻击序列不会因多枚弹体同时擦过而反复扣血。

| 妖怪 | 起手与实际招式 | 应对方式与反击窗口 |
| --- | --- | --- |
| 小影团 | 缩身 0.9 秒，标出跃击落点；向前跃进，落地小范围命中 | 看见落点圈后离开圈内，等落地再接近；收招约 1.1 秒 |
| 晶石偷儿 | 侧步蓄势 1.0 秒，沿逐渐加宽的预警方向冲刺；追击会尝试侧向绕行 | 横向走出冲刺带，避免顺着它的方向逃跑；冲刺遇障碍会停止，收招约 1.1 秒 |
| 风车捣蛋怪 | 帽子转动 1.1 秒后，发射三枚分叉风弹 | 观察弹道间隙，横向移动或借实体障碍阻挡；贴近也要等它出手后的收招 |
| 月水泡妖 | 普通体起手 1.2 秒，精英体 1.5 秒；交替使用扩散水环和三枚泡弹，精英水环范围更大 | 在环形波纹扩大前离开范围，或及时向外穿过前沿；泡弹需观察三路间隔。精英 60% 生命处记录新阶段 |
| 荆棘木妖 | 起手 1.65 秒，轮换三路根刺、锁定落点重砸、扇形挥枝 | 根刺走空隙，重砸离开圈，挥枝避开正前方。首领收招约 2 秒并显露核心；55% 生命处记录阶段 |
| 风车守卫 | 起手 1.5 秒，先释放一条风道；55% 生命后改为两条分叉风道 | 提前离开画出的风道，选择两道之间或侧面的安全地面；收招时接近星盘，核心窗口约 2.2 秒 |
| 石甲守卫 | 起手 1.4 秒后直线冲撞，遇障碍停止；60% 生命后穿插三片旋转甲刃 | 冲撞前横向移开；甲刃绕转时避开刀片覆盖方向。直冲后收招 2.6 秒，核心窗口最长 3.5 秒 |
| 吞灯妖 | 各阶段起手 1.8 秒；70% 以上移影后发射四枚暗星，70%—35% 发射五路星弹，35% 以下使用留下安全扇区的扩散暗环 | 先观察移影落点，再避开弹道；末段进入标有“安全”的扇区或离开暗环范围。70% 和 35% 两个阶段点保存，便于就近重试 |

普通妖怪会巡逻、发现并追击玩家、沿可行走区域绕障碍，离开活动范围后返回。首领未显露核心时大幅减伤，常规命中只结算四分之一伤害；收招、盾击、回声协作等能提供显露窗口。第三段攻击可以帮助创造机会，不能替代观察预警。

## 六类陷阱的节奏

表中时间是 **星灯探险家模式的机关时钟秒数**。小小守护者以 0.84 倍速度推进，提示和间歇更长；勇敢冒险家为 1.12 倍。不同机关有固定相位差，不能假定整张地图同时安全；进入区域有短暂启动缓冲。

| 机关 | 基础节奏 | 危险行为 | 如何通过 |
| --- | --- | --- | --- |
| 星刺地板 | 每 3.8 秒一轮：预警 1.05 秒、尖刺伸出 0.75 秒、休息 2 秒 | 矩形地板范围内伸刺，基础伤害 16 | 看边框和孔位亮起，等尖刺缩回后通过；与边框留一点距离 |
| 间歇喷焰 | 每 4.8 秒一轮：预警 1.4 秒、喷焰 1.25 秒、休息 2.15 秒 | 朝固定方向喷出约 370 像素长的窄扇形，基础伤害 20 | 从扇形侧面绕过，或等待停火；实体阻挡会挡住喷焰判定 |
| 古钟摆锤 | 持续沿预先画出的摆弧来回运动，标准周期约 3.81 秒 | 长约 175 像素的摆臂带动锤头，按真实扫过位置判定，基础伤害 22 | 不站在摆弧里等待；观察锤头经过后再横穿，也可绕出摆动范围 |
| 星矢机关 | 每 4 秒一轮：瞄准预警 1.25 秒，随后一次发射三支分叉飞矢 | 飞矢速度 430 像素/秒、最长存活 2.1 秒，基础伤害 16；会被实体障碍挡住 | 看到虚线后横向离开射线；关闭发射器后，也要避开已经飞出的箭 |
| 月潮漩涡 | 每 5.5 秒一轮：预警 1.5 秒、活跃 2.3 秒、休息 1.7 秒 | 约 145 像素内向中心吸引，进入中心约 56 像素才造成基础伤害 18 | 预警时离开圈，不等吸引开始再靠近中心；必要时利用御风或水罩帮助脱离 |
| 龟裂石板 | 踩上后预警 1.1 秒，坍塌 2.3 秒，再恢复 2 秒 | 活跃时站在板上会受到基础伤害 15，并返回最近安全点 | 裂纹亮起后及时离开，不在板上等；等待重新恢复后通过 |

机关基础伤害还会经过当前难度倍率和队伍防御结算。陷阱不能依靠普通正面盾面格挡减伤；水罩的有效时间可以辅助通过。出生地和营地周围设有安全保护，机关位置也与主线目标、营地保持距离。

每个陷阱旁有一根独立拉杆。脱战后靠近拉杆，情境键显示“关闭机关”，互动后该机关停止；关闭记录写入当前关卡的区域存档，重进仍有效。六类机关均支持关闭，已发射的飞矢则会继续飞行至碰撞或失效。

## 失败、休息与保存

受击后有 1 秒保护，同一持续攻击不会在一帧内多次扣血。倒下时回到最近营地、恢复生命和最低补给；等级、装备、已完成目标、已开宝箱、已关闭机关及首领阶段保留。营地休息恢复生命、把红星果至少补到两个，同时重置未解木箱并让妖怪重新活动。

`campaign.json` 记录队伍成长、已解锁主线及首领阶段；`campaign.json.world.json` 记录每组主线的目标、机关状态、宝箱、探索迷雾、营地及已关闭陷阱。两份存档均有临时写入和备份；区域存档损坏时会尝试读取备份，并保留仍可读取的条目。v0.1 的成长存档继续兼容，新的开放区域检查点从入口建立。
