# v1.3.0 · 音乐与剧情朗读

七个开放区域都有独立的原创器乐，标题、普通战斗、首领战另配三首，共十首。单曲 64–96 秒，合计约 13 分 44 秒；包括竖琴、木管、钢琴、弦乐、吉他、马林巴与轻打击乐。换场景自动交叉淡化，战斗结束后平滑回到区域曲，暂停菜单降低音乐音量。

## 可控制的中文旁白

全部七章开场、二十一组通关正文与结局都有中文朗读：共 28 段独立录音，约 6 分 18 秒；最后一关和结局复用同一文件。旁白仅朗读故事，奖励数值和操作提示仍以文字显示。录音文件随安装包提供，游玩时不需要联网或安装系统语音包。

剧情窗口提供“暂停朗读 / 继续朗读”“重新朗读”和“跳过剧情”；原来的继续按钮可直接继续旅程，不必等朗读结束。跳过会即时停止声音，正常推进当前剧情一次，不会重复发放奖励。朗读不会自动关闭剧情窗口；玩家可以自行阅读后继续。非剧情的死亡提示与重开确认不会自动朗读。

旁白播放时背景音乐自动压低，结束、暂停或跳过后恢复。暂停菜单的声音设置可分别调节音乐、音效、旁白音量，并关闭以后剧情的自动朗读。设置独立保存在 `user://audio_settings.json`，不影响成长存档。
