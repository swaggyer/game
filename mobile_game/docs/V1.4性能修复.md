# 星灯岛 v1.4.0 · 安卓性能与操作响应修复

针对用户在一加13T上反馈的首图走路、战斗卡顿，修复渲染提交过多、首次动作资源加载和触控松手后才响应的问题。

## 原因与处理

- 原版每张地图将大量草叶、花朵等静态矢量细节逐个提交；首图桌面基线约1.56万次绘制调用。现合并为保留颜色与位置的分块三角网格，让远处细节能按块裁剪。地面着色使用预计算噪声纹理代替大量逐像素正弦运算，保留柔和草地、水岸与自然色彩。
- 原版在高分辨率手机上按屏幕原生分辨率绘制复杂地表。移动端改用720逻辑高度、随长宽比扩展的视口和线性缩放，以稳定60帧为目标；桌面设置保持独立。目标帧率不是本机真机实测保证。
- 首次转向、走路或攻击曾同步读取动作贴图。动作贴图和常用音乐在加载阶段预热并保留资源，避免战斗期间反复读取同一首音乐。
- 攻击原先等手指松开才触发；技能也在松开时才起手。现在按下立即响应，命中仍遵守既有起手、接触、收招阶段，保留妖怪伤害与挑战难度。失去焦点或进入菜单会取消按住的互动，不会误触发。
- 血量界面不再每帧创建头像边框样式，未变化的文字不重复赋值，摇杆静止时不重复重绘。HUD信息最多每0.1秒更新，输入、战斗和角色移动保持每帧处理。
- 可直达目标的同伴、妖怪不再无条件执行A*；导航指引复用短距离内未变化的路线。战斗判定、弹丸、预警仍持续更新。
- 每12秒自动存档改为后台写入独立快照；关键互动、暂停和进入后台前等待写入完成并保存最新状态，避免旧快照覆盖新进度。保留原存档格式与备份恢复。
