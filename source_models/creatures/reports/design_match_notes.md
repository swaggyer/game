# 造型与交付说明

本目录为实际可编辑的 Blender 网格源、独立 GLB 与透明 PNG 渲染，不是把概念图贴在平面上。

## 龙族精修

三阶段龙已经按 `concepts/dragon-board.png` 调整为四足、细长颈口鼻、青玉身体、奶油鬃毛、金角、金边叠鳞、翅膀及星尾。模型 ID 和文件路径保持稳定。

当前是圆润简化制作网格，未逐片复刻概念图的精细雕刻与细密金线花纹；老龙王的衣饰为简化肩披与长鬃毛，没有概念图中的完整长袍。

## 妖怪

8 类妖怪保留了各自的识别轮廓和故事道具：影团、偷晶小鬼、风车捣蛋怪、月水泡妖、荆棘木妖、风车守卫、石甲守卫、吞灯妖。

妖怪目前为简化的圆润卡通造型，与 `concepts/monsters-board.png` 的精细设定有细节差异，例如毛发、烟雾层次、木纹缠绕、布料和繁复装甲。实际模型效果以本目录透明渲染和 GLB 为准。

## 动画与使用范围

- 动画为根物体的呼吸/浮动/摇摆变换；龙翼通过关节空物体摆动。
- GLB 已合并导出为单个场景动画片段，便于播放器同时播放浮动与摆翼。
- 没有骨骼蒙皮，也没有完整攻击、受击和行走动作集。
- 小龙与新龙王提供四方向静止透明 PNG。PNG 可以直接作为 2D 精灵素材；GLB 和 Blender 文件可继续制作动画或渲染更多方向。
- 多部件网格保留了可编辑性；若改作手机实时 3D 渲染，需要进一步合批、简化或制作 LOD。

`validation.json` 检查独立 GLB 结构、动画轨道、实际三角面数量，以及透明 PNG 的 alpha 与画面边缘。造型对应关系另经人工目视检查。
