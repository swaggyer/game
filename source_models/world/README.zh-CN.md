# 星灯岛：环境与道具源资产

本目录是《星灯岛与回家的小龙》的第一版环境与道具资产库。所有模型均由真正可编辑的网格或曲线构成，包含颜色、粗糙度、金属度及部分发光材质；没有把整张概念图当成三维模型。

## 内容

- `world_library.blend`：25 件道具的排布总库，每类道具有独立命名集合。
- `props/*.glb`：25 件可独立导入 Godot 的道具。
- `scenes/*.blend` / `scenes/*.glb`：家庭村庄、萤火森林、风车原野、月光水乡、旧王遗迹、星灯岛，共 6 个小型立体场景。
- `renders/*.png`：25 张 512×512 的透明背景道具图、6 张 1200×1000 的场景预览及一张总库预览。
- `reports/manifest.json`：真实文件路径、每项网格数量、求值后三角面数量、包围盒与状态说明。
- `scripts/build_world.py`：可重新生成资产的 Blender Python 源码，适配本机 Blender 5.4 Alpha 的节点名称本地化情况。

## 道具

亮/暗星灯柱、龙王灯、关闭/打开宝箱、星钥匙、普通晶石、火/风/水/空间源晶、石桥、木桥、镜面机关、可推木箱、风车机关、星门、补给篮、苹果、路牌、圆冠树、蓝杉树、水车、古代拱门、龙王座。

## 使用

1. 使用 Blender 打开 `.blend` 可编辑几何、材质和构图；总库按集合整理。
2. Godot 项目建议导入 `.glb`，避免把 `.blend` 导入流程绑定到本机 Blender 的安装路径。
3. 2D 制作可直接使用透明 PNG 作为静态道具精灵；场景预览是完整构图，不是可直接平铺的 TileMap 图块。
4. 所有三维源使用 Blender Z 向上、米为单位；导出 GLB 遵循 glTF 的 Y 向上坐标转换。

## 当前范围

这是静态美术资产包。没有宣称已经完成关卡碰撞、寻路、可交互逻辑、动态水流、自动开箱或骨骼动画。场景是可拆分修改的美术小景；正式关卡需继续按玩法扩建和配置交互。场景 `.blend` 为便于查看包含摄影机、灯光和预览背景；`.glb` 导出时仅包含实际场景几何，不包含摄影用背景平面。

所有文件均在新的 `StarLanternIsland/source_models/world` 目录生成，没有覆盖旧游戏或原角色模型。
